Chatbot Settings

How to use

  1. Open the settings panel and paste your OpenAI API key.
  2. Select the model you want to use and adjust the system prompt.
  3. Ask questions in the chat box — responses come directly from ChatGPT.

Security note

This demo calls the OpenAI API directly from the browser. For production apps, proxy requests through your own server so you can protect your API key and apply usage limits.
